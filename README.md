# dsh-session-span

**简体中文** | [English](README.en.md)

## 引言

按“一个任务对应一个会话”的方式工作时，往往会关心两件事：这项任务已经投入了多少时间，以及它是从什么时候开始的。当前版本的侧边栏只显示最近一条消息距今的时间，无法回答这两个问题。为此，本插件只补充会话的起始时间与总用时，不涉及其他功能。

## 功能

在侧边栏会话行的悬停卡片中增加两行信息：

- **会话已用时**：从第一条消息到当前时刻的时间；会话空闲期间继续累计，卡片打开期间每 30 秒更新一次。
- **第一条消息时间**：按设备所在时区显示，日期格式随界面语言变化（英文界面为 `2026-11-19 09:12`）。

```
会话名称
C:\Users\Administrator
3 分钟前                        原有信息：最近一条消息距今的时间
已用时 3 小时 12 分              本插件：从第一条消息至今
第一条消息 2026年11月19日 10:57   本插件：起始时间
● 运行中
```

## 安装

在应用内打开「设置 → 插件 → 添加插件」，填写 `dsh-session-span`，然后启用「会话历时」插件包。

在由命令行管理的 `web` 等配置中安装：

```sh
dsh plugin --profile web add dsh-session-span
```

桌面版的配置由应用管理，请在应用内的插件页面安装。

运行要求：DSH `>=0.2.2-rc.3`，Node `>=22.6`。本插件没有依赖，也没有安装脚本。

## 起始时间的确定方式

- 起始时间为会话记录中第一条由用户或定时任务发起的消息。由定时任务创建的会话同样具有起始时间。
- 由其他会话分叉得到的会话，以自身的创建时间为起始时间，不沿用原会话的第一条消息。
- 该时长由 DSH 在宿主侧根据完整的会话记录计算并缓存，随会话摘要供侧边栏读取，因此分页、压缩与重启都不会改变结果。
- 插件安装之前已经存在的会话没有缓存结果，首次悬停时会读取一次，此后结果被缓存；记录较长的会话，首次悬停时该部分可能稍后出现。

## 说明与限制

- 显示的是实际经过的时间，包含会话空闲的时段。若需要了解实际执行所花费的时间，输入框下方的统计栏显示的是模型用时与工具用时之和。
- 本插件不向模型注入内容，不向外部发送数据；除计算出的起始时间外不保存其他状态。
- 可在「设置 → 插件」中停用或卸载，悬停卡片会恢复原有内容。

## 开发

本包按现状发布，没有构建步骤：宿主侧为普通 ESM 模块，客户端为注册到 `sidebar.session.row.hover` 插槽的浏览器模块。

```sh
# 让某个配置指向本仓库
dsh plugin --profile web add /absolute/path/to/this/directory
```
